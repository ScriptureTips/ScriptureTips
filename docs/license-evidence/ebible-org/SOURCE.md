## What it says

Site-wide Intellectual Property Policy (`legal.php`): the site mixes public-domain and copyrighted works; each copyrighted work is licensed individually under its own terms, shown on its own details/copyright page; no blanket license applies. Modern translations are assumed copyrighted unless dedicated to the public domain. The About page says contributed translations must carry a free-sharing license (CC0, CC-BY-SA, CC-BY-ND, CC-BY-ND-NC) or be public domain. So the per-text evidence folders remain the authority for each text; this folder records the distributor's own framework. `ippolicy.php` (the "Legal" link target) redirects to `legal.php`.
