Getting it

The downloads page links to the extension for each browser. It runs in Chrome and other Chromium browsers, and in Firefox 140 or later.

After it's installed there is nothing to set up: open any page with a scripture reference on it and the reference is a link.

Updates

Your browser updates the extension by itself. This help is kept for each version: the version you are reading about is shown at the foot of every topic, with links to the others.

Coming from version 1.0.3

Version 2 is an update to the same extension, so it arrives by itself, and it asks for no new permissions.

  • Your settings are kept: your reading sites, the one you chose, your link format and the sites you turned the extension off on.
  • The tooltip shows the passage itself in the translation you choose.
  • If your links still go to another site and you would rather they opened the ScriptureTips reader, change where links go.
