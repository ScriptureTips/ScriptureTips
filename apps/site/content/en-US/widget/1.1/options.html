Options are the second argument of the first call to run. All are optional.

ScriptureTips.run("main", {
  translation: "bsb",
  ignore: ".byline",
  hoverDelayMs: 500,
});
OptionWhat it setsDefault
translationThe translation passages open in: a translation's ID."eng-kjv"
schemeThe verse numbering your pages use: kjv, hebrew, latin or greek."kjv"
ignoreA CSS selector for what to leave out.None
destinationWhere links go: "scripturetips", or an address pattern."scripturetips"
destinationTranslationAn outside destination's own code for its translation.None
siteThe ScriptureTips reader that links open.{{site}}
hoverDelayMsHow long the pointer rests on a link before the tooltip opens, in milliseconds.300
stringsThe tooltip's words, to reword or translate them.English
storageWhere visitors' translation choices are kept: null keeps them only until the page is closed.The page's localStorage
apiThe ScriptureTips API passages are read from.{{data}}/api

The tooltip's words

strings replaces any of these:

ScriptureTips.run("main", {
  strings: {
    loading: "Loading…",
    failed: "That passage couldn't be loaded.",
    missing: "This translation doesn't have that passage.",
    readMore: "Read more",
    translation: "Translation",
    more: "…",
    tooltip: "Scripture passage",
    pin: "Keep open",
  },
});
