A linked reference, and Read more in its tooltip, open in a new tab. By default that is the ScriptureTips reader at {{siteHost}}, at the passage, in the tooltip's translation.

Another Bible site

Set destination to an address pattern, and destinationTranslation to that site's own code for the translation to open:

ScriptureTips.run("main", {
  destination: "https://www.biblegateway.com/passage/?search=ST_REFERENCE&version=ST_TRANSLATION",
  destinationTranslation: "NKJV",
});
WordBecomesFor John 3:16
ST_REFERENCEThe whole referenceJohn 3:16
ST_BOOKNAMEThe bookJohn
ST_CHAPTERThe chapter3
ST_VERSEThe verse16
ST_TRANSLATIONdestinationTranslationNKJV

The tooltip still shows the passage from ScriptureTips; only the links' address changes. Without destinationTranslation, ST_TRANSLATION is the ID of the translation in the tooltip.

Another ScriptureTips installation

To open links in a church's or community's own ScriptureTips reader, set site to its address:

ScriptureTips.run("main", { site: "https://scripture.example.org" });
