The tooltip is kept apart from your page's styles, so your CSS can't break it and its CSS can't touch your page. To make it match your site, set these CSS variables on your page:

VariableSetsDefault
--st-accentLinks, the pressed pin, focus outlines#0054a5
--st-inkThe passage's text#1d232a
--st-mutedVerse numbers, the credit, labels#5b6672
--st-paperThe background#fff
--st-ruleBorders#dfe3e6
--st-radiusHow round the corners are6px
--st-fontThe fontThe system's interface font

The text is 15 pixels whatever your page's own text size is, and your page's fonts, spacing and other CSS never reach the tooltip: only these variables do.

For example, a dark tooltip with a serif font:

:root {
  --st-paper: #1f2430;
  --st-ink: #f2efe6;
  --st-muted: #b8bcc8;
  --st-rule: #3a4152;
  --st-accent: #ffcf70;
  --st-radius: 0;
  --st-font: Georgia, serif;
}

The links

The links themselves are ordinary links in your page, with the class st-ref, so your own CSS styles them:

a.st-ref { text-decoration-style: dotted; }
